# Анализ безопасности кода

## Материалы

`project/` содержит небольшой HTTP-сервис проектных документов: исходный код,
SQLite-базу в виде SQL-фикстуры, описание API и штатного поведения,
функциональные тесты. Python 3.11+, внешних зависимостей нет.
Все данные и учётные записи синтетические.

## Задача

Проанализируйте код на наличие уязвимостей. Определите, где поведение сервиса
нарушает правила доступа из `project/README.md`, при каких условиях это
можно использовать и к каким последствиям это приводит.

Исходные материалы изменять нельзя. При необходимости проверяйте локальную
копию проекта, без обращения к внешним системам.

Результат сохраните в единственном файле `output/report.md` в свободной форме.
