# Аудит конфигураций

## Материалы

`project/` содержит комплект развёртывания сервиса записей: Dockerfile,
Compose, настройки Nginx, небольшой HTTP-сервис, служебные файлы
и функциональные тесты. Назначение компонентов и штатное поведение описаны
в `project/README.md`. Все данные и учётные записи синтетические.
Версия входных материалов — 1.0.0; контрольные суммы — в `manifest.json`.

## Задача

Проанализируйте конфигурации на наличие проблем безопасности. Найдите настройки,
которые нарушают описанные границы доступа или дают компонентам избыточные
полномочия, оцените условия использования этих проблем и их влияние.

Уязвимости сторонних пакетов, внешний TLS, выпуск паролей, резервное копирование
и ротация секретов вне задания. Наличие демонстрационных паролей само по себе
не является находкой.

Исходные материалы изменять нельзя. При необходимости проверяйте локальную
копию в изолированном стенде. Конфигурации предоставлены для аудита
и не считаются безопасными; Docker для анализа не обязателен.

Результат сохраните в единственном файле `output/report.md` в свободной форме.
